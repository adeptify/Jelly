# Workspace V1 验收记录 — 2026-08-12

## 结论

上一版“内部可用”的结论因笔记页图标重叠、编辑入口不可见、灵感分类串到其他模块等真实界面问题被撤回。本轮修复后，已用最终 ZIP 解压出的 `0.2.1 (3)` 应用重新完成笔记与灵感主动线验收，可以作为内部可用版本合入 `main`。

这仍不等于公开发行：当前包使用临时签名，尚未做 Apple Developer ID 签名、公证和更新分发。

## 本轮关闭的阻塞项

- 笔记页改为自适应浏览/编辑布局；窄窗口先选笔记再进入编辑，宽窗口保持双栏，不再用悬浮图标覆盖搜索框。
- 新建笔记后直接显示标题和正文输入区，正文为空时明确显示“开始写点什么…”。
- 最近、全部、归档改为互斥范围，不再把同一篇笔记同时重复显示在多个列表。
- 笔记与灵感统一使用日历的暖色背景、分隔线、选中态和控件强调色，去掉突兀的系统蓝灰大块选中态。
- 灵感的分类筛选和分类管理收回模块内部，移除会泄漏到笔记页的全局工具栏“分类”。
- 灵感补齐待处理、已成笔记、归档三个状态范围；转为笔记后显示“打开笔记”，不再误导用户重复转换。
- 灵感列表行补齐整行点击命中区和可访问性选中状态，Computer Use 可稳定打开详情。
- 灵感元数据状态改为中文；URL 元数据失败时保留原始链接并允许重试。
- 版本更新为 `0.2.1 (3)`。

## Computer Use 真实产品测试

最终复验应用来自 ZIP 的全新解压路径：`/private/tmp/Jelly-0.2.1-3-final.bOOELP/Jelly.app`。数据使用隔离目录 `~/Library/Application Support/JellyAcceptanceData.FtKKJX`，没有写入日常数据。

### 笔记主线

- 从空状态新建笔记，标题和正文输入位置清楚可见。
- 实际输入标题；通过系统粘贴向 Block 编辑器写入正文，正文搜索可找到该笔记。
- 退出并重启最终应用，标题和正文仍然存在。
- 将笔记安排到日历，笔记内可查看关联事项；点击关系可打开准确日历事项。
- 浅色和深色模式均检查过布局、文字对比度、选中态和输入区。
- 笔记归档、恢复和永久删除由模型与视图模型自动化覆盖；本轮 Computer Use 没能稳定展开笔记省略号菜单，因此不声称完成了这三项真实点击。

### 灵感主线

- 从空状态捕获文本，打开详情并转为笔记；转换后导航到准确的新笔记。
- 回到灵感后，“已成笔记”范围显示该条目，详情主操作为“打开笔记”。
- 在真实界面完成归档和恢复。
- 捕获 `https://example.com/jelly-qa`，元数据失败时保留原始 URL；域名搜索、复制链接和重试入口均可用。
- 复制后的剪贴板内容与原始 URL 一致。
- 永久删除确认对话框已打开并取消；没有执行最终不可恢复删除。
- 浅色和深色模式均检查过布局、文字对比度、筛选和详情动线。

### 跨模块与视觉

- 笔记页不再出现灵感的“分类”按钮，也没有图标压住搜索框。
- 灵感分类入口只在灵感浏览区内部出现；日历原有分类入口不受影响。
- 笔记与灵感都沿用日历的暖色语义主题，三模块之间不再像三套独立产品。
- 修复前后截图见 [视觉审查](notes-inspiration-design-audit-2026-08-12.md)。

- 公开发行前仍需 Developer ID 签名、公证、安装与升级演练。

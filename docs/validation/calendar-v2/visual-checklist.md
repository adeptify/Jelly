# 个人月历 V2 原生视觉与交互清单

验收对象必须从最终 `dist/个人月历.app.zip` 新鲜解包，或从最终 `dist/个人月历.dmg` 只读挂载后复制到本机；不得使用 `.build/debug` 代替。当前九项均为 `PENDING / NOT RUN`。

| # | 原生检查步骤 | 需要记录的证据 | 状态 |
| --- | --- | --- | --- |
| 1 | 依次点击窗口左上、右上、左下、右下附近日期的空白区域 | 四张创建卡就近锚定截图；卡片超边时翻向可用空间；标题自动聚焦 | PENDING / NOT RUN |
| 2 | 从月末正向拖到下月，再从下月反向拖回月末 | 拖动中的连续范围高亮；松手后的起止日期；两种方向归一化一致 | PENDING / NOT RUN |
| 3 | 全屏连续向前、向后各滚动至少 52 周并跨越多个月份 | 起止位置与中途跨月截图／录屏；内容扩展无跳位；工具栏标题跟随中心周 | PENDING / NOT RUN |
| 4 | 在同一天建立 11 条事项，包含跨日与单日项目 | 前 10 条直接可见、第 11 条 overflow 文案与抽屉完整列表；同一跨日来源不重复 | PENDING / NOT RUN |
| 5 | 拖动普通跨日条带主体，再拖左右真实外端 handle，分别执行 Command-Z | 移动保持跨度／时间；两端缩放只改对应边界；每次撤销完整恢复 | PENDING / NOT RUN |
| 6 | 对重复跨日条带分别选“仅本次”“本次及以后”“取消”，另制造一次保存失败后重试 | 三种范围结果、取消零变更、失败提示与重试后单次持久化 | PENDING / NOT RUN |
| 7 | 建立含范围、完成、分类和重复例外的数据，彻底退出并重启最终包 | 重启前后同一数据对照截图，身份、范围与状态均保持 | PENDING / NOT RUN |
| 8 | 恢复一份 schema 1 备份，再尝试损坏／语义无效备份 | 有效迁移后的 V2 数据；无效恢复前后 primary 哈希一致；错误提示不丢上下文 | PENDING / NOT RUN |
| 9 | 在浅色／深色分别检查五组色板与极端自定义色；使用 VoiceOver；开启减少动态效果 | 全局与近景截图、对比度／可读性观察、VoiceOver 顺序与完整 label/value、减少动态后仍完成滚动对齐与浮层目标状态 | PENDING / NOT RUN |

## 记录规则

- 每项只在真实完成且证据路径可追溯时改为 `PASS`；局部完成写明 `PARTIAL` 与未完成边界。
- 原生鼠标拖选、拖动、缩放不能由纯函数测试或源码检查代替。
- 重启持久化必须使用最终打包应用及其真实 Application Support 数据；测试夹具不代替此项。
- VoiceOver 与减少动态必须实际启用系统功能，不能只引用 accessibility label 或 motion policy 单测。
- 若任何一项失败，记录复现步骤、预期／实际、截图或录屏路径及是否发生数据写入；不要用后续成功覆盖失败证据。

# Jelly 安装说明

Jelly 是一款 macOS 个人日历应用。收到安装包后，按下面步骤安装即可。

---

## 系统要求

- Mac 电脑（**Apple 芯片**：M1 / M2 / M3 / M4 等）
- macOS **14** 或更高版本  
- **不支持** 老款 Intel 芯片的 Mac

不确定自己是不是 Apple 芯片：点击左上角  → **关于本机**，芯片一栏若写着 Apple M 系列即可。

---

## 你收到的文件

二选一即可：

| 文件 | 说明 |
|------|------|
| `Jelly.app.zip` | 压缩包，下载后解压使用 |
| `Jelly.dmg` | 磁盘镜像，打开后把 App 拖到「应用程序」 |

---

## 安装步骤

### 方式 A：用 ZIP（最常见）

1. 下载 `Jelly.app.zip`
2. 双击解压，得到 **Jelly** 应用
3. 把 **Jelly** 拖到「应用程序」文件夹（也可放在桌面）
4. **不要直接双击打开**（见下方「首次打开」）

### 方式 B：用 DMG

1. 下载并双击 `Jelly.dmg`
2. 将窗口里的 **Jelly** 拖到「应用程序」
3. 推出（推出）该磁盘镜像
4. 到「应用程序」里找到 Jelly，按「首次打开」操作

---

## 首次打开（重要）

当前版本使用个人测试签名，macOS 会提示无法验证开发者，**这是正常现象**。

请按下面任一方式打开：

### 推荐：右键打开

1. 在 Finder 中找到 **Jelly**
2. **按住 Control 键点击**图标（或双指点按 / 右键）
3. 选择 **打开**
4. 在弹出对话框中再点 **打开**

之后从启动台或「应用程序」正常双击即可，一般不会再拦。

### 若提示「已损坏」或「无法打开」

1. 打开「终端」（启动台 → 其他 → 终端）
2. 输入下面命令后回车（路径按你实际放置位置改）：

```bash
xattr -cr /Applications/Jelly.app
```

若 App 在桌面：

```bash
xattr -cr ~/Desktop/Jelly.app
```

3. 再按上面的 **右键 → 打开** 试一次

### 系统设置里允许

1. 打开 **系统设置 → 隐私与安全性**
2. 往下找「已阻止使用 Jelly」之类提示
3. 点击 **仍要打开**

## 使用说明（简要）

- 数据保存在本机，不会上传到云端
- 首次打开会自动创建本地数据；卸载 App **不会**自动删除你的日历数据
- 可通过菜单进行备份导出 / 恢复（若版本已包含该功能）

---

## 常见问题

**Q：双击没反应 / 闪一下就没了？**  
先确认是 Apple 芯片 Mac，并用「右键 → 打开」。仍不行时执行上面的 `xattr -cr` 命令。

**Q：提示无法验证开发者？**  
正常。用右键打开，或在「隐私与安全性」里选「仍要打开」。

**Q：Intel Mac 能用吗？**  
目前这一版不行，仅支持 Apple 芯片。

**Q：可以装在几台电脑上？**  
可以。每台电脑各自保存自己的数据，互不同步。

**Q：如何卸载？**  
把 `Jelly.app` 移到废纸篓即可。若也要删数据，可再删除：

`~/Library/Application Support/PersonalCalendar/`

（删除后日历内容无法恢复，请先备份。）
